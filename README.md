# MonPremierProjet - TP N°2 Développement Mobile

**École :** École Supérieure de Technologie de Nador (ESTN)
**Filière :** ILCS - S3
**Module :** Développement Mobile
**Réalisé par :**Karabila Ibtihal et Salma Bouchta

## Description

Premier projet Android : anatomie d'un projet (AndroidManifest.xml, java/, res/)
et débogage avec LogCat et points d'arrêt.

## Technologies

- Android Studio
- Langage : Java
- Minimum SDK : API 21 (Android 5.0)
- Package : `com.estn.monpremierprojet`

## Fonctionnalités

- Affichage d'un message de bienvenue défini dans `strings.xml`
- Bouton "Cliquer ici" avec écouteur de clic
- Logs `Log.i`, `Log.d` et `Log.e` (TAG : `TP2_DEBUG`)
- Débogage avec points d'arrêt

## Lancer le projet

1. Cloner le dépôt :
```bash
   git clone https://github.com/ibtihalkarabila/TP2_Mobile.git
```
2. Ouvrir le dossier dans Android Studio et attendre la synchronisation Gradle.
3. Choisir un émulateur ou un smartphone, puis cliquer sur Run ▶.
4. Ouvrir Logcat et filtrer avec `tag:TP2_DEBUG`.
